# 🐾 NeuroPet: Emotion-Based Virtual Companion

NeuroPet is a C++-based interactive virtual companion that simulates emotional behavior, user interaction, and adaptive responses using structured programming principles.

---

## 🌟 Features

* **Emotion System**
  Tracks internal states such as hunger, happiness, and energy

* **Dynamic Emotional States**
  Automatically updates between states like *balanced, tired, excited, low,* and *irritated*

* **Interactive Conversation Module**
  Provides context-aware responses based on the user's input and mood

* **Realistic Feeding System**
  Different food choices affect the pet’s internal state and behavior

* **Mini-Games**
  Simple interactive games to increase engagement and influence pet emotions

* **Autonomous Behavior**
  The pet expresses needs such as hunger, fatigue, or low emotional state

---

## 🧠 Concept

This project models a simplified human-like interaction system using **state-driven logic**.

The virtual pet adapts its responses based on:

* Internal conditions (hunger, energy, happiness)
* External input (user actions and mood)

This creates a more engaging and dynamic interaction, simulating basic elements of emotional intelligence in a console-based environment.
